# LGO Visual Reference Delivery v0.36.0

## What this ZIP contains

1. `docs/reference-art/v0.36.0/` — required M6 combat visual reference images for v0.37.
2. `docs/reference-art/future-reference-v0.36.0/` — extra UI/world/web/admin references for later tasks.

## Install into repo

From repo root `LinhGioiOnline`:

```bash
unzip -o /path/to/lgo-m6-visual-reference-pack-v0.36.0.zip -d .
find docs/reference-art/v0.36.0 -maxdepth 1 -type f | sort
```

## Use order

1. Run/finish v0.36 docs/reference-pack prompt if not already done.
2. Unzip this package into repo root.
3. Run v0.37 Combat Visual Image Ingest + Readability Polish prompt.
4. Do not use the `future-reference-v0.36.0` folder to expand scope without a separate prompt.

## Important

This package is visual reference only. It is not final production art and not a license/provenance-final asset pipeline.


## Codex usage

Read `LGO-M6-VISUAL-REFERENCE-PACK-v0.36.0-CODEX-USAGE.md` first. Copy the prompt in that file to Codex after unzipping this pack into the repository root.
