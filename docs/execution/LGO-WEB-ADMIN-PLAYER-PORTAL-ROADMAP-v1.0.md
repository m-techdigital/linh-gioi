# Linh Gioi Online Web Admin Player Portal Roadmap v1.0

Decision marker: LGO_MASTER_ROADMAP_ACCEPTED_v1.0.

Code governance applies through `docs/execution/CODE-OWNERSHIP-MAP.md`.

## Public Website

- Can start earlier as a player-facing landing website.
- Game-style presentation with Linh Gioi visual identity.
- Marker: game-style.
- No production auth or account data required.

## Player Portal

- Starts after Auth/DB.
- Shows account, characters, profile, progression, and support status only after security boundary is accepted.

## Admin-Dev Console

- Starts after roadmap/content ownership is accepted.
- Ops-first with Linh Gioi skin.
- Marker: ops-first.
- Used for dev validation, content inspection, and smoke evidence review.

## Admin-Prod Console

- Starts after Auth/DB/content/economy and security review.
- Requires audit, roles, rollback, moderation, and production monitoring.

This roadmap does not implement web, portal, or admin surfaces.
