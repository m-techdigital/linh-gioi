# Linh Gioi Online Asset Animation Pipeline Roadmap v1.0

Decision marker: LGO_MASTER_ROADMAP_ACCEPTED_v1.0.

Code governance applies through `docs/execution/CODE-GOVERNANCE-CONTRACT.md`.

## Pipeline

- Reference art packs guide direction only.
- Runtime placeholders remain simplified and readable.
- Production sprite sheets require provenance/license notes.
- Animation direction must define idle, walk, interact, skill, impact, recovery, NPC, monster, and VFX states before import.
- UI atlas/import settings must be documented before production UI art claims.
- Visual evidence must classify generated screenshots, owner acceptance, and production-art status separately.

No final production art is claimed by this roadmap.
