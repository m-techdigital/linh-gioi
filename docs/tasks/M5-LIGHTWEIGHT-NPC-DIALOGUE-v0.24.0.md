# M5 Lightweight NPC Dialogue v0.24.0

Decision marker: M5_LIGHTWEIGHT_NPC_DIALOGUE_SOURCE_READY_v0.24.0

Adds a local-only dialogue foundation for the Gate Keeper. The panel advances through short scripted lines, closes locally, then hands the player to the existing Training Stone objective.

This is local-only dialogue, not a quest database, branching dialogue system, reward system, inventory, relationship, chat, production auth, DB persistence, protocol, or GameData schema change.
