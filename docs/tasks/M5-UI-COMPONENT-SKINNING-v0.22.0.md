# M5 UI Component Skinning v0.22.0

Decision marker: M5_UI_COMPONENT_SKINNING_SOURCE_READY_v0.22.0

Scope:

- Apply a lightweight runtime UI skin to the existing playable shell.
- Use v0.20 component and window/popup reference direction for frame accents, chips, buttons, and status toasts.
- Preserve existing auth, lobby, character selection, world entry, movement, save-position, and guided training semantics.

This is not a production UI art pass and does not add new gameplay systems.

Frozen surfaces remain out of scope:

- `protocol/**`
- `gamedata/schemas/**`
- `docs/adr/**`
- `client/Unity/Assets/Game/UI/design-tokens.json`
