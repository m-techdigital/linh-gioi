# LGO Content Taxonomy v1.0

Marker: `LGO_CONTENT_TAXONOMY_READY`

## Scope

Define a stable content taxonomy for future maps, NPCs, dialogue, training objects, skills, effects, and events without changing GameData schemas.

## Non-Claims

- No gameplay implementation.
- No GameData schema change.
- No new content database.
- No economy, rewards, inventory, social, guild, party, market, or live-ops implementation.

## Exit Gate

`tools/validate_lgo_content_taxonomy.py` prints `LGO_CONTENT_TAXONOMY_VALIDATION_PASS`.
