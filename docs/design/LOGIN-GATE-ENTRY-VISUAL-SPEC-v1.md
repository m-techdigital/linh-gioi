# Login Gate Entry Visual Spec v1

Status: LGO_LOGIN_GATE_ENTRY_VISUAL_CLOSED_v1

Quality classification: STRUCTURAL_RUNTIME_PLACEHOLDER_V2

This spec describes temporary presentation wiring using V2 structural placeholders. It does not accept V2 as final visual quality or production art.

## Presentation

The Login / Gate Entry screen should read as a cultivation fantasy gate rather than a development form:

- full-screen Spirit Gate background from V2;
- logo/title stack at top-left;
- compact gate entry panel using V2 panel skin;
- Gate Keeper NPC visual as guidance;
- server selector row with server icon and online dot;
- clear primary action `Vào Thế Giới`;
- secondary utility actions with icons and Vietnamese labels.

## Constraints

- Dev-key flow remains the existing prototype account flow.
- No production auth, register, OAuth, email/password, or DB persistence.
- Player-facing text is rendered in Unity UI code.
- Reference-only and composite images are not imported into Unity.
