# Design Boards

These SVGs are non-production planning references. They are safe to keep in the source tree because they do not create scenes, prefabs, gameplay content, protocol changes, or runtime behavior.

| File | Purpose |
|---|---|
| `roadmap-flow.svg` | Milestone overview from M0 to alpha readiness. |
| `m0-to-m1-gate.svg` | Visual gate showing why M1 remains locked until Unity/runtime evidence is accepted. |
| `core-gameplay-loop.svg` | Early loop for M1 offline combat. |
| `hud-wireframe.svg` | Mobile-first HUD layout reference. |
| `world-hub-wireframe.svg` | Later world hub/nav reference for M2/M3. |
| `production-board.svg` | Team/sandbox workflow board. |

Do not treat these as final art. Any production UI must still use the design token system and pass Unity runtime verification.
