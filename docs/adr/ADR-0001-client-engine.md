# ADR-0001 — Client Engine

**Status:** Accepted

## Decision
Use Unity 6.3 LTS and C# for the production game client.

## Context
The approved North Star visual requires stylized 3D characters, animation, VFX, scalable mobile rendering and PC/mobile deployment. The earlier Java/libGDX direction remains viable only for a much simpler 2D target.

## Consequence
Java remains a backend technology, not a requirement for client gameplay code.
