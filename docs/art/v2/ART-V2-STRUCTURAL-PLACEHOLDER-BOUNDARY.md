# ART V2 Structural Placeholder Boundary

Status: STRUCTURAL_RUNTIME_PLACEHOLDER_V2

ART V2 separated asset classification:

- structural runtime placeholder;
- import proof and mapping proof;
- temporary UI layout proof;
- not final visual quality;
- not production art.

Allowed:

- temporary Login/Gate Entry visual scaffold;
- temporary world/combat placeholder hookup;
- validator coverage for separated PNG provenance, import path, `.meta` settings, and no reference-only imports;
- Vietnamese UI text rendered by Unity code.

Not allowed:

- no claim that V2 is polished final runtime art;
- no production screenshots or marketing-quality acceptance based on V2;
- no baked English labels copied from review/contact images into runtime UI;
- no replacement of ART V3B high-resolution separated runtime asset requirements.

Replacement rule:

Every V2 runtime use must be replaceable by ART V3B assets without changing gameplay semantics, protocol messages, GameData schemas, ADRs, or design tokens.
