# LGO Art v1 Runtime Asset Boundary

Status: LGO_ART_V1_REFERENCE_ONLY_ACCEPTED

## Allowed

- Use Art Pack v1.1 boards and composite sheets as visual references.
- Keep experimental crops in `docs/reference-art/v1/runtime-asset-pack/**` for audit and review.
- Use existing runtime-approved individual PNGs already present in Unity.
- Polish layout, frame hierarchy, labels, and readable grouping with code-owned Vietnamese UI copy.

## Not Allowed

- Do not import visual direction boards into Unity.
- Do not import screen mockups into Unity.
- Do not import overview guides into Unity.
- Do not import whole composite UI/world sheets into Unity.
- Do not import arbitrary crops from composite sheets into Unity runtime.
- Do not claim production art or final runtime asset pack from composite-derived crops.
- Do not bake English labels from art references into runtime UI.

## Current Runtime Source

The current accepted runtime art source remains:

- `client/Unity/Assets/Game/Art/Combat/Placeholders/Resources/CombatPlaceholders/**`

The Art v1 crop set remains reference/evidence only until replaced by ART_V2 separated assets.
