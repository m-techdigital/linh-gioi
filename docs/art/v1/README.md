# LGO Art Pack v1

Status: LGO_ART_V1_EXPERIMENTAL_SLICE_REVIEW_REQUIRED

Art Pack v1.1 is a controlled visual placeholder package for Linh Giới Online after `M6_COMBAT_FOUNDATION_CLOSED_LOCAL_v0.55.0`.

The pack is not production art. After quality review, its visual direction board, screen mockups, and overview guide are reference-only. Its UI/world/combat composite sheets are experimental-source-only and must not be treated as a final runtime asset pack.

Runtime-approved assets require individual transparent PNG files with clean alpha, no baked UI text, no attached neighboring assets, checked size/import settings, and provenance notes. Missing production-grade runtime art is tracked as `MISSING_RUNTIME_ASSET` for ART_V2.
