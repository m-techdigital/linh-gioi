# ART V1 Reference-Only Boundary

Status: LGO_ART_V1_REFERENCE_ONLY_ACCEPTED

ART PACK v1.1 classification:

- reference/mockup/art direction only;
- composite UI/world/combat sheets are not runtime source;
- existing crop outputs, if present, are `experimental-source-only` evidence;
- no V1 reference board, mockup, overview guide, or composite sheet may be imported into Unity;
- no V1 slice may be used to claim runtime-approved, production, or final visual-quality art.

Current boundary decision:

Auto-slicing/cropping from ART PACK v1.1 composite sheets is stopped. Existing generated slices are kept only under docs reference paths when needed for audit/history and must remain replaceable by separated source assets.

Forbidden:

- no Unity runtime import from V1 composite sheets;
- no production art claim;
- no final runtime asset pack claim;
- no protocol, GameData schema, ADR, or design-token changes.
