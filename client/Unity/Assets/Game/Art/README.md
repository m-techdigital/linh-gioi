# Linh Gioi Runtime Placeholder Art

These are original source placeholders for early runtime slices. They are intentionally small, deterministic SVG assets and may be replaced by production art later.

Naming rules:

- `lgo_<category>_<role>_<variant>.svg`
- lowercase ASCII, underscores only
- keep source placeholders under `Assets/Game/Art/<Category>`
- keep generated/cache output out of source

Folder purposes:

- `Characters`: playable hero silhouettes and class markers
- `NPCs`: non-hostile quest/service silhouettes
- `Monsters`: hostile target silhouettes
- `Items`: inventory/equipment icons
- `Skills`: ability icons
- `Maps`: ground tiles and environment markers
- `UI`: frames, buttons, and interface symbols
- `VFX`: simple effect/interaction markers
- `Shared`: palette notes and reusable motifs
